# MiroInd demo scenarios

These examples are fictional inputs for the credential-free MiroInd MVP. They
are designed to exercise the report workflow, not to represent real brands,
policies, customers, or public sentiment.

Run the local app with `npm run dev:miroind`, open
`http://localhost:3000/miroind`, and copy one JSON file's fields into the form.
The files can also be submitted directly to `POST /api/miroind/runs`.

Included scenarios:

- `regional-service-launch.json` — a hypothetical app launch with regional access and local-fit questions.
- `hypothetical-pricing-update.json` — a fictional pricing announcement with urgency and trust risks.
- `creator-announcement.json` — a fictional creator message with a clear, relationship-led tone.
